# 预注册：权重封顶的确认性复验（SECURITY_V4）

- 冻结时间：2026-09-29，SECURITY_V3 结果已知，SECURITY_V4 结果产生之前。
- 背景：SECURITY_V3 的 H1（全部劫持单元攻击成功率显著下降）未满足，按其采用规则 D4 未成为默认。V3 同时显示，D4 在所有观察单元中都不劣于 D3，且大幅恢复可用性。本复验只检验这一在 V3 中产生的假设，**使用从未用过的新种子**，其余全部与 V3 相同。
- 代码：`privedge/experiments/security_v3.py --seeds 601,709,811,907,1009 --tag v4`（与 V3 同一脚本、同一 κ=2、同一攻击参数）
- 数据：Massive-STEPS、Olist、美团 TRD。

## 判定（逐数据集）
- C1 不回退：每个场景 × ε 中，D4−D3 攻击成功率均值 ≤ +0.02，且 D4−D3 NDCG@10 均值 ≥ −0.02。
- C2 可用性恢复：hijack_1src、demote_1src（被攻破源数 f=1 < t=2）的每个 ε 下，D4−D3 NDCG@10 的目标级 95% 区间下界 > 0。
- 攻击成功率的下降幅度只做描述，不判定（V3 显示它依赖 ε 和数据异质性）。

## 采用规则
三套数据的 C1、C2 都满足时，D4（`weight_cap=2.0`）成为 v4.1 主线默认；否则保留 D3，把权重劫持列为已知局限。
