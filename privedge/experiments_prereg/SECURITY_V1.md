# 预注册：投毒攻防实验 v1

- 冻结时间：2026-09-29，在任何真实数据攻防结果产生之前
- 代码：`privedge/experiments/security_v1.py`
- 输出：`runs/security_v1/<run_id>/`

## 数据与划分
- 开发数据：Massive-STEPS 7 个城市×时期服务器（156 类），每个服务器轮流作目标，其余为源。
- 若 Olist 通过预注册 Gate A–C，用同一脚本、同一参数一次性运行，作为第二真实数据集。
- 每源抽 5,000 用户；抽样、扰动种子与 `dataset_research/scripts/massive_steps_ldp_diagnostic.py` 相同，使无攻击、无防御条件可与已记录结果逐项核对。
- ε ∈ {1, 2}；种子 {101, 211, 307, 401, 503}；发布 Top-20；评价 Top-10；上下文用目标自身公开上下文。

## 攻击
- 目标类别：每个（目标服务器, 种子）用独立种子从"源真实分布平均值排名第 31–80 的类别"中均匀抽 3 个（攻击者想把冷门类别推进新区 Top-10）。
- 被投毒源：用独立种子从源中随机选。
- 场景：clean；MGA 伪造用户（占该源诚实用户比例 β ∈ {0.02, 0.05, 0.10}，1 个源）；MGA β=0.05，2 个源；被攻破的发布者（合法签名，把 3 个目标类别频率设为该源最高频率，1 个源和 2 个源）。

## 防御配置（阈值全部在此固定）
- D0 无防御：团队原始 `censor_aware` 融合，直接使用源发布值。
- D1 仅发布端过滤：联合支持项集检测，候选 2m=40，z 阈值 6，保留比例 0.7。
- D2 仅网关：留一法共识截尾 clip_z=3、rel_floor=0.25，多源支持 t=2。
- D3 = D1 + D2。

## 指标
- 攻击成功率 = 3 个目标类别中进入预测 Top-10 的比例（主指标）。
- 效用：Recall@10、NDCG@10（相对目标真值，仅离线计算）。
- 过滤器：伪造报告移除率、诚实报告误删率；无攻击时的误删率。
- 统计单元为目标服务器（种子取平均），报告均值与目标级 bootstrap 95% 区间。

## 预先声明的判定
- 防御有效：D3 相对 D0 的攻击成功率在所有攻击场景下均下降，且区间上界 < 0。
- 代价可接受：clean 场景下 D3 相对 D0 的 NDCG@10 下降不超过 0.02（区间下界不低于 −0.04）。
- 任一条件不满足，如实报告，不调整阈值后重跑同一批数据；若需修改，新建 v2 并在 Olist 或新种子上验证。
