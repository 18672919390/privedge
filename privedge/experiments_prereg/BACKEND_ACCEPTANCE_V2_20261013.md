# 后端集成验收方案 V2（2026-10-13）

本方案在本轮实现和验收前建立。验证证据读取、构建、目录迁移与接口集成；不运行A8统计实验，不生成准确率或鲁棒性优越性结论。

1. 新增独立的 `/api/evidence/a8`，保持既有 `/api/evidence` 五块响应不变。未登记数据集显示 `NOT_RUN`，不返回伪造数值。
2. 登记读取必须校验固定目录、运行ID、预注册、manifest、原始结果及summary的哈希、数据集、种子和四方法覆盖。不适配方法必须给出书面原因。缺失指标为null并说明原因；损坏或不一致的数据集为 `INVALID`，不展示数值，也不替其他数据集隐藏错误。
3. 测试使用临时目录的明确合成夹具，绝不写入runs或作为实验结果登记。验证完整结果、未运行、不适配、重复或不成对条件、非法数值、路径越界、哈希损坏、登记即时更新。
4. 完整测试与前端构建须通过；三套固定合法请求继续按V1参数核对决策和离线评价，现有证据响应及受保护文件哈希保持不变。
5. 在独立迁移目录使用现有解释器验证启动所需文件、三数据预测、静态资源、实验读取、账本副本篡改拒答及测试。不联网安装、不复用迁移目录中的开发虚拟环境。该检查仅是本机迁移验收，不能代替另一台电脑从零安装。
6. 若能使用本地浏览器，检查五页面及三数据切换、预测、账本演练。页面文案、A8图表和最终截图由前端负责人交付；记录当前缺口。

结果保留在 `competition_entry/docs/v4/backend_validation/20261013_v2/`。失败保留并注明修复。旧运行、原始数据及research_core不变。代码变更记录08第7节；新工程证据使用E22，A8须另行登记。真实第二电脑、算法实验与证明交付不能记成已完成。
