# PrivEdge 网关聚合的容错定理与证明

2026-10-15复核修订：依据算法交付的证明与当前实现，定理2及引理A—D统一收紧为`n≥3、f<(n−1)/2`，保证留出任意来源后仍有诚实严格多数。旧条件不足以证明诚实源封顶权重下界；这不是默认算法改动，也不宣称旧条件下最终份额界已被反例推翻。复核说明与性质检查见E27。定理1不变。

对应代码：`privedge/decision.py::robust_top_k`、`privedge/robust.py::{winsorize_releases, capped_weights}`、`privedge/gateway.py::admit`。
默认参数：支持阈值 t=2，截尾系数 c=3，相对下限 ρ=0.25，权重封顶 κ=2，截尾下限 0。

## 1 模型

- 网关接受 n 份摘要，来自 n 个**互不相同**的已注册数据源。前提由两条检查保证：
  - 注册表把每个密钥绑定到一个 (数据源, 角色)；
  - `admit` 对同一数据源在一次请求中的多份摘要一律拒收（EQUIVOCATION）。
- 其中 f 个数据源被攻破，集合记为 F。被攻破者持有合法签名密钥，可以发布任意内容：任意类别集合、任意频率（有限值）、任意正方差。其余 n−f 个是诚实源，记为 H。
- 源 s 发布的类别集合为 M_s，频率为 x_{s,i}，自报方差为 σ²_{s,i}。
- 定理2仅讨论无上下文、来源已准入且每源一份摘要的路径；摘要非空、类别不重复、频率有限、方差有限且为正，诚实发布频率非负。公开上下文分支不在证明内。
- 支持数 sup(i) = |{s : i ∈ M_s}|。网关只在候选集 A_t = {i : sup(i) ≥ t} 中排序并输出 Top-k。

## 2 定理 1（支持规则的容错界）

**定理 1.** 对任意 f 个被攻破源发布的任意内容，网关输出中的每个类别 i 都满足

  |{h ∈ H : i ∈ M_h}| ≥ t − f。

**证明.** 输出 ⊆ A_t，所以 sup(i) ≥ t。这些支持者中至多有 f 个属于 F，于是至少 t−f 个属于 H。证明不涉及频率、方差、截尾或融合权重。∎

**推论 1（注入免疫）.** 若 f < t，则**没有任何诚实源发布过的类别不可能进入输出**，与攻击者报告的数值无关。默认 t=2 时，单个被攻破的发布者无法注入新类别。

**推论 2（界是紧的）.** 若 f ≥ t，攻击者只需让 t 个被攻破源都发布目标类别，就能让它进入候选集 A_t。这个界不能再改进。实证：在合成数据上，f=t=2 时 300/300 次注入成功；f<t 的 400 组随机对抗（任意类别集合、频率 ±10⁶、方差 10⁻¹²–10²）全部满足定理 1（`tests/test_core.py::test_support_rule_theorem_under_arbitrary_adversaries`）。

**代价.** 一个真实热门类别若只被少于 t 个诚实源发布（区域特色），也会被排除。提高 t 就是用这类召回换取更大的容错 f。SECURITY_V2：Massive 上 ε=1 时 t=3 使 2 源合谋的攻击成功率从 0.98 降到 0.29，无攻击 NDCG 下降 0.039；TRD 有 10 个源，代价为 0。

**与实验的对应.** SECURITY_V2 中 t=1 与 t=2 的输出完全相同，因为截尾已经压住了单源注入。所以 t=2 的作用是提供一个不依赖统计假设的保证，而不是提供实验增益。

## 3 定理 2（有界影响：截尾 + 权重封顶）

记诚实源在类别 i 上的"稠密值" v_{h,i}：发布了就取发布频率，没发布就取该源最小发布频率的一半（`robust._dense`）。定义

- 诚实最大值 M_i = max_h v_{h,i}，诚实极差 R_i = max_h v_{h,i} − min_h v_{h,i}，诚实最大方差 V_i；
- 诚实原始权重 w_h = 1/max(√(平均自报方差), 10⁻¹²)，与实现的标准不确定度下限一致；其最大值为 W，最小值为 w。

**假设（留一诚实多数）.** n≥3且f<(n−1)/2。无论留出的是诚实源还是被攻破源，其余n−1个源中诚实源均严格过半。仅要求f<(n+1)/2不能保证留出诚实源后的权重中位数下界。

**引理 A.** 在诚实多数下，任何按留一方式计算的中位数都落在诚实值的区间内。

证明：设其余源共 N=n−1 个，其中被攻破的 N−|H| 个严格少于 N/2。中位数取的是第 ⌈N/2⌉ 个或第 ⌊N/2⌋+1 个顺序统计量。这个位次大于被攻破源的个数，所以取到的值不小于诚实最小值；又不大于诚实源的个数，所以不大于诚实最大值。numpy 在 N 为偶数时取中间两个的平均，两者都在区间内，平均值也在。∎

**引理 B（上界）.** 对被攻破源 s，截尾后的值 x̃_{s,i} ≤ U_i，其中

  U_i = M_i + c·√(V_i + (1.4826·R_i)² + (ρ·M_i)² + 10⁻¹⁰)。

证明：截尾上限由留一统计量构成，逐项放大：
- 共识（中位数）≤ M_i（引理 A）；
- 离散度 1.4826·MAD：共识在诚实区间内，所以诚实偏差都 ≤ R_i，再由引理 A 得 MAD ≤ R_i；
- 噪声项取其余源方差的中位数，≤ V_i（引理 A）。

代入截尾上限的公式即得 U_i。∎

**引理 C（下界）.** 截尾下限为0，所以x̃_{s,i}≥0；融合时未发布的类别也按0计。这给出当前计算的单源贡献下界，不比较改变发布集合、peer统计和权重后的反事实排序。

**引理 D（权重份额）.** 在 κ ≥ 1 且诚实多数下，被攻破源的融合权重总份额

  α ≤ fκW / ((n−f)·w + fκW)。

证明：
- 被攻破源的权重 ≤ κ·(其余源权重的中位数) ≤ κW（引理 A）。
- 诚实源的权重封顶后 ≥ min(w_h, κ·中位数) ≥ min(w, κw) = w。
- 代入份额的定义即得。∎

若额外满足诚实权重相近，才可使用W≈w的示例；相同样本量不能单独推出这一条件。n=10、f=1、κ=2且W=w时，得α≤2/11≈0.18。没有封顶时，攻击者可通过谎报极小方差取得极高权重（SECURITY_V3中只有截尾和t=2时，NDCG最多下降0.66）。

**定理 2.** 在诚实多数、κ≥1、截尾下限 0 的条件下，记 S_i^H 为**当前这组输入里**诚实源截尾后的值，按各自封顶权重做的加权平均。它不是无攻击时的融合分数：诚实源的截尾上限和权重中位数都按留一计算，攻击者的数值会进入这些统计量。对任意类别 i，

  (1−α)·S_i^H ≤ S_i ≤ (1−α)·S_i^H + α·U_i。

证明：设被攻破源的实际权重份额为 α_F ≤ α（引理 D），则 S_i = (1−α_F)·S_i^H + α_F·A_i，其中 A_i 是被攻破源截尾后值的加权平均，满足 0 ≤ A_i ≤ U_i（引理 B、C）。

- 下界：A_i ≥ 0，且 S_i^H ≥ 0（有截尾下限），所以 S_i ≥ (1−α_F)·S_i^H ≥ (1−α)·S_i^H。
- 上界：截尾后的诚实值都 ≤ M_i ≤ U_i，所以 S_i^H ≤ U_i。于是 (1−α_F)·S_i^H + α_F·U_i 随 α_F 单调不减，取 α_F = α 即得上界。∎

注：诚实源自己的截尾上限也由留一中位数决定，攻击者可以间接影响它；但在 f < (n−1)/2 时，这个上限仍不低于诚实最小值。因此定理 2 限制的是攻击者在**这一次融合**里所占的权重份额，不能直接读成“与无攻击输出的差距不超过 α”。0.18 这个例子还要求诚实源权重相近（W≈w）；诚实源方差差很大时，α 的上界会变大。

**含义.** 无论攻击者报什么数值、谎报多小的方差：
- 它把任一类别分数抬高的幅度不超过 α(U_i − S_i^H)；
- 它把任一类别分数压低的比例不超过 α。

再结合定理 1，f < t 时被注入的只能是诚实源本来就发布过的类别。这解释了 SECURITY_V4 的结果：单源权重劫持（含降级）攻击下，D4 的 NDCG 与无攻击相差在 0.09 以内；仅有截尾和 t=2 的 D3 相差 0.03–0.68，其中降级攻击为 0.42–0.68。

## 4 局限（如实）

- 定理2需要留一诚实多数（n≥3、f<(n−1)/2）；数值界依赖诚实源间异质性R_i。不能只凭界较松推断某次攻击成功的原因。Olist的5个源在该条件下只覆盖f=1；f=2的实验不属于本定理保证范围。
- f ≥ t 时定理 1 不提供保证，只能靠定理 2 限制幅度。SECURITY_V4 中 2 源劫持在 ε=1 时仍几乎总能注入。
- 定理只针对网关聚合。伪造用户（MGA）由发布端过滤处理，属于统计检测，没有最坏情况保证。β=2% 且 ε=1 时它低于检测阈值。
