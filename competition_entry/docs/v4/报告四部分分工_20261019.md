## 五、修改与合并流程

1. 每人从 GitHub `main` 拉最新（提交 `429478f`），复制一份主报告 docx，**只改自己负责的节**。
2. 打开 Word“修订”模式；不要改别人的段落；需要改别人内容时，用批注写明，不直接改。
3. 每人交回：docx（带修订）+ 一页修改说明（改了哪些节、为什么、涉及哪些图/数字）。
4. 测试负责人按“修订”逐条接受/拒绝，合并成主报告；队长复核摘要、第一章、第四章、最终 PDF。
5. 合并后必须：
   - 重导 PDF；
   - 同步 TOC 页码；
   - 核对图表编号；
   - 更新 `提交前核对单` 的报告哈希；
   - 再推 GitHub。
6. 不要直接改 GitHub 网页上的 docx；二进制文件冲突无法合并。
