# 初赛提交清单（2026-10-19）

## 一、官方要求（来源见文末）

- 官网：中国研究生创新实践系列大赛平台 `https://cpipc.acge.org.cn/`
- 报名截止：**2026-10-18**；作品提交截止：**2026-10-22**
- 队伍：1–4 名在读研究生 + 1 名指导教师；不允许跨校、跨单位组队
- 官方模板包包含：作品报告、作品原创性声明、作品重大改进说明（如适用）、校内通知
- 作品报告要求：A4；除标题外宋体、小四、1.5 倍行距；**不得出现学校、院系、指导教师等身份信息**；摘要 **500 字以内**；章节为摘要、五章正文、参考文献（可微调）
- 报名后需学校研究生院审核（通知中有校内联系方式）

## 二、初赛要交什么

| 材料 | 是否必需 | 说明 |
|---|---|---|
| 作品报告 | 必需 | 官方模板结构；PDF 提交，DOC 留底 |
| 作品原创性声明 | 必需 | 官方模板；填作品名称；团队成员签名、日期（指导教师签字按平台要求） |
| 作品重大改进说明 | 视情况 | 仅当作品曾参加过往届同一大赛且本次有重大改进；首次参赛不需要 |
| 可执行程序/演示材料 | 平台字段决定 | 模板包未单列；通常在官网“作品附件/程序链接”提交。需确认单附件大小上限与格式 |
| 作品简介 | 平台字段决定 | 官方模板包未列；若平台有“简介”字段再填，现有简介 PDF 可作素材 |

> 官网提交页的具体字段（附件、链接、简介、视频等）以登录后的页面为准；本清单按官方模板包和参赛通知整理。

## 四、风险与待办

1. **报名截止 10-18 已过**：如果还没报名，今天必须联系学校研究生院确认补报或审核状态。
2. **提交截止 10-22**：还剩 3 天。
3. **程序 63.2 MB**：先确认平台单附件上限；若不够，把 ZIP 放可长期访问的云盘，把链接和 SHA-256（`939cb8462df7d10f09ad94e917cf02793d5aae6fdf6c80e41d171439a6b6280a`）写进报告附录或提交说明。
4. **原创性声明**：必须用官方模板，填作品名称，成员签名；指导教师签字按平台要求。
5. **封面日期**：填实际提交日；作品名称与平台一致。
6. **匿名**：报告已检查，无学校/姓名/导师信息；提交前再通读一遍封面、页脚、附录。
