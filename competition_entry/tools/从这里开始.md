# PrivEdge 团队资料包：从这里开始

这是我们参加第五届研究生网络安全创新大赛（创意作品赛）的作品 PrivEdge 的完整材料：代码、数据、实验结果、设计文档、报告初稿、图表、演示控制台和任务清单。**仅限队内使用，请不要公开传播**：作品要求原创，部分数据许可也只允许非商业使用。

## 第一步：看文档（不用装任何东西）

打开 `文档` 文件夹，里面是 Word 版文档，图和公式都在里面，手机上也能打开。建议顺序：

| 顺序 | 文件 | 内容 | 用时 |
|---|---|---|---|
| 1 | `07_项目全景说明（团队共享版）.docx` | **最重要**：我们要做什么、已经做了什么、缺陷与局限、时间计划、常见问题 | 40 分钟 |
| 2 | `09_任务清单（待认领）.docx` | 剩下的全部任务：做什么、交付什么、需要什么能力、工作量、截止 | 15 分钟 |
| 3 | `04_作品报告初稿.docx` | 报告初稿（按获奖报告的章节结构写的完整初稿） | 40 分钟 |
| 4 | `08_相对团队原始研究代码的改动记录.docx` | 和团队原始研究代码相比，沿用、重写、新增了什么 | 15 分钟 |
| 5 | 其余 | `01` 设计、`02` 每个数字的来源、`03` 定理证明 | 按需 |

对文档有意见，直接在 Word 里用"审阅 → 修订 / 批注"标出来发回队长。Word 版由 `competition_entry/docs/v4/` 下的 Markdown 原件生成，最终以原件为准，队长合并修改后会重新生成。

## 第二步：认领任务

看完 07 和 09 后，在 `任务认领表.csv`（用 Excel 打开）里自己想做的任务那一行填上名字，发回给队长；也可以直接在群里说。

## 第三步：在自己电脑上跑起来（Windows）

1. **装 Python 3.12**（<https://www.python.org/downloads/>），安装时勾选 **"Add python.exe to PATH"**。
2. 进入 `privedge` 文件夹，依次双击：
   - `setup.bat`：安装依赖，第一次需要几分钟（要联网）；
   - `run_tests.bat`：应显示 `45 passed`；
   - `start_console.bat`：自动打开浏览器 <http://127.0.0.1:8765/>，就是演示控制台。关掉黑色窗口就停止。

数据（`privedge/data/`）和构建好的前端（`privedge/web/dist/`）都已在包里，只看控制台不需要装 Node.js。要改前端才需要 Node 18+：`cd privedge\web`，然后 `npm install`、`npm run build`。

**形式化验证（可选）**：从 ProVerif 官网 <https://bblanche.gitlabpages.inria.fr/proverif/> 下载 2.05 版 Windows 二进制，放到 `tools\proverif\proverif2.05\proverif.exe`（`tools` 与 `privedge` 同级）。然后在 `privedge` 文件夹里打开 PowerShell 运行：

```powershell
$env:PYTHONPATH = (Get-Location).Path
.\.venv\Scripts\python.exe -m privedge.experiments.formal_v1
```

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击 `.bat` 弹出"Windows 已保护你的电脑" | 点"更多信息"→"仍要运行" |
| `setup.bat` 提示找不到 Python 3.12 | 重新安装 Python 并勾选 Add to PATH，然后重开文件夹再双击 |
| `pip install` 很慢或失败 | 换网络，或用国内镜像：`.venv\Scripts\python.exe -m pip install -r requirements.lock -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| 控制台提示 8765 端口被占用 | 关掉之前开的控制台窗口再试 |
| 解压后路径太长、报错 | 解压到较短的路径，例如 `D:\PrivEdge` |

## 改东西之前

- 先看 07 第 11 节的协作规则；改完代码跑一遍 `run_tests.bat`，并在 `08` 第 7 节追加一行记录；
- 不要修改 `privedge/runs/` 下已有的运行目录和 `review/` 下的原始研究代码；
- 报告里的每个数字都要能在 `02_实验证据登记` 里找到来源；
- 代码统一由队长维护的私有仓库汇总。改好的文件发给队长合并，不要各自另存多份版本。
