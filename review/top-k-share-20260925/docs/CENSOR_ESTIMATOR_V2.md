# 第二步：从 censor-aware 评分到可分析估计器

日期：2026-09-14。状态：数学工作稿、独立原型和探索性诊断；不是最终论文方法。
第一步定义见 RESEARCH_DEFINITION_V1.md。公共上下文来源尚未落实，因此所有目标推断
结论仍以允许的 q 可用为条件。本步骤不改变旧 fusion.py 或既有主机实验结果。

## 1. 先澄清原方法究竟近似了什么

旧方法使用发布值的二次损失、未发布值的 -log Phi 损失、上下文先验以及经验迁移方差。
目标函数冻结参数后可以是凸的，但“能优化”不等于“得到正确的目标分布”。

一个更精确的参照：若完整估计向量 Y 的各坐标独立、连续，密度 f_i(y;theta_i) 已知，
观察到 Top-m 的索引 L 及其未处理的数值 y_L，tau=min(y_L)，则在合法排序区域内，
其联合观测似然（以带标签索引及连续值为观察）为

    L(theta; L,y_L) = product_{i in L} f_i(y_i;theta_i)
                      * product_{j not in L} F_j(tau;theta_j).

推导：对未发布坐标在 (-infinity,tau] 上积分，独立性使积分分解。
这里 tau 是观测值的函数，随机性本身并不使这个联合似然成为近似。
它不同于条件在“某个固定列表已被选中”后的条件似然，后者有额外的选择概率归一化。

当前代码不能直接宣称实现了上述精确模型，原因包括：LDP 离散估计、估计坐标的联合
相关性、未知源目标偏移、发布值非负处理、用选择后的估计计算方差，以及数据依赖权重。
例如 OUE 在固定原始数据条件下有独立扰动位，但总体采样层会引入另一层随机性；
不能将给定数据的独立性直接推广为无条件总体估计模型。PEM 还存在前缀剪枝。

因此第二步先建立一个明确的凸替代目标，不把它称为精确选择似然。以后若发展似然法，
应从上述联合观察模型和协议具体分布出发，而不是仅因看到 Phi 项就称其为 Tobit 模型。

## 2. 新原型的观察范围

文件：censor_estimator.py。只接受已发布 ServerRelease 与公共 q，不接收隐藏分布。
暂支持诚实 GRR/OUE/OLH 的完整域估计后 Top-m 发布，显式拒绝 PEM/攻击摘要标签。
完整公开元数据封装仍是第一步审计中的待改进项；本原型不从配置读取真实用户信息。

所有 d 个物品联合估计 theta in Delta_d={theta>=0,sum theta=1}。
完整域潜变量允许保留候选集外概率质量；最终输出可限制在源候选并集，或显式选择
full-domain 输出模式。两种模式不可混用候选覆盖上界。

设公开频率 y_s,i、最小公开值 tau_s；b>=0 是声明的迁移容差，c>=0 是删失松弛量。
构造每个源和物品的区间：

    已发布正值：I_s,i = [max(0,y_s,i-b), y_s,i+b]
    已发布零值：I_s,i = [0,b]
    未发布项：  I_s,i = [0,tau_s+b+c]。

区间上界可超过 1，下界也可能超过 1，体现与概率域冲突的观测；不偷偷重新归一化发布值。
这些是软约束：数据噪声或迁移可使真值落在区间外，不要求所有区间同时可行。
b 和 c 不是已知真实 TV 距离，也不是置信半径；本诊断固定 b=.02,c=0。
未发布的 plug-in 方差不可见，暂以该源已发布方差中位数作为代理，明确不声称准确。

精度系数 a_s,i 由发布方差倒数构造，先用全设计的正精度中位数归一化，再截在
[0.1,10] 并除以源数。权重在优化前冻结；归一化是尺度约定，不是新的统计保证。
无删失消融只将未发布项 a 置零，其余系数完全相同，避免改变权重造成混杂。

## 3. 目标函数和凸性

给定 lambda>0：

    F(theta) = 1/2 sum_s,i a_s,i dist(theta_i,I_s,i)^2
               + lambda/2 ||theta-q||_2^2，theta in Delta_d。

令 r_s,i(theta_i)=max(theta_i-u_s,i,0)+min(theta_i-l_s,i,0)，则

    grad_i F = sum_s a_s,i r_s,i(theta_i) + lambda(theta_i-q_i)。

命题 A：F 为 lambda-强凸、连续可微；梯度的一个 Lipschitz 常数为

    L = lambda + max_i sum_s a_s,i。

证明：到闭区间的平方距离的一半为凸且梯度 1-Lipschitz；非负加权和保留凸性，
加上 lambda 二次项获得强凸性。单纯形是紧凸集，故存在唯一最优解 theta*。
这是给定观察数据的确定性结论，允许系数来自该观察；不自动给出统计无偏性。

算法：theta_0=q，重复 theta_{t+1}=Proj_Delta(theta_t-grad F(theta_t)/L)。
每次梯度 O(Sd)，单纯形投影 O(d log d)。不使用 SciPy、不逐物品独立拟合后再归一化。

## 4. 可检查的优化证书

定义 Frank-Wolfe 型间隙：

    G(theta)=max_{z in Delta}<grad F(theta),theta-z>
            =<grad F(theta),theta>-min_i grad_i F(theta)。

命题 B：对任意可行 theta，0<=F(theta)-F(theta*)<=G(theta)，且

    ||theta-theta*||_2 <= sqrt(2 G(theta)/lambda)。

证明：凸性给出函数差上界；强凸性加上约束最优解的一阶变分不等式给出
F(theta)-F(theta*)>=lambda/2||theta-theta*||²，合并即可。
实现返回目标值、G、优化 L2 上界、迭代数和 converged；达到迭代上限不能伪报收敛。

重要：这个区间只控制数值解与该目标最优解的距离，不是与 p_T 的距离。
不能把 optimization_l2_bound 写成用户分布估计置信区间。

## 5. 从优化误差到统计问题的桥梁

对任意真实 p in Delta（仅证明和评估可用），强凸性和变分不等式还给出：

    ||theta*-p||_2 <= ||grad F(p)||_2 / lambda。

证明：lambda||theta*-p||² <= <grad F(theta*)-grad F(p),theta*-p>；
其中 <grad F(theta*),theta*-p><=0，再用 Cauchy-Schwarz。
因此数值解满足

    ||theta_hat-p_T||_infinity
    <= ||grad F(p_T)||_2/lambda + sqrt(2G(theta_hat)/lambda)。

若右边小于 Delta_k/2，且最终候选包含真实 Top-k，则恢复正确排序集合。
这是确定性的充分条件，不是现有实验已经建立的高概率恢复定理。

梯度残差可以明确拆开：

    grad F(p_T) = lambda(p_T-q) + sum_s a_s .* r_s(p_T)。

第一项是先验失配；第二项是采样/LDP 噪声、选择和迁移共同造成的区间残差。
如果未来可以建立同时成立的 |r_s,i(p_T,i)|<=e_s,i 界，则可进一步用
||p_T-q||_2 + ||sum_s a_s .* e_s||_2/lambda 控制统计部分。
当前没有这样的可部署 e，因此不能读取模拟真值构造“置信界”再传给算法。
固定先验强度与系统偏移也可能造成不消失的偏差，不声称 n 趋于无穷时一致。

## 6. 与旧方法的关系和仍需攻克的问题

本原型是一条可分析的替代路线，尚未证明比旧 Gaussian/Phi 评分更准确。
明确改进是：联合概率约束、完整域概率质量、显式软迁移区间、严格凸性和优化证书。
尚待解决：如何从公开元数据校准噪声界、如何估计/限制迁移偏差、选择后的方差代理是否
可靠、联合 LDP 协方差怎样进入估计，以及适合实际 q 质量的正则化策略。
目前区间法可能比对数 CDF 更弱，也可能因失配 q 的高维总质量受损；诊断必须报告失败。

## 7. 本次验证设计

experiments/validation/diagnose_censor_estimator.py 固定 12 个新种子、3 个条件、3 个协议：
源目标完全一致/原生成器迁移/迁移加误导上下文。域128、每源1500、6源、k10、发布20。
所有方法共享发布，各协议每源使用同样的初始种子，保证源采样数据匹配。
同一条件下每个种子是配对单位；条件之间不视为独立重复。

预先指定 lambda=.1 和 1 两个敏感性点，不在此数据上挑一个再称为确认实验。
基线：average、原 censor-aware、context_only、归一化源平均与 q 的 0.5 线性融合。
消融：同系数下移除未发布项损失。另比较源候选输出和完整域输出。
报告 Recall/NDCG/coverage、概率估计 L2/Linf 误差、优化间隙、收敛标记、实际目标间隔。
配对 bootstrap 区间仅为探索性逐项区间，不作为校正后的显著性结论。

输出独立保存到 outputs/censor_estimator_v2_diagnostic，不覆盖旧结果。
复现：在 top-k 目录运行 `./.runtime/python/python.exe experiments/validation/diagnose_censor_estimator.py`。
再次运行会重算并覆盖该独立诊断目录；原始配置、种子和代码摘要随结果保存。

第二步本轮验收是：模型/近似清楚、定理带证明、可执行估计器、针对数学性质的测试、
实际诊断与结论。高概率统计界和论文级最终算法属于后续工作，不以本轮原型替代。
