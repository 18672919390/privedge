# 研究定义 v1：新服务器究竟能知道什么

日期：2026-09-14。性质：研究设计工作稿，用于约束实现和实验，不是论文成稿。
当前范围是明确任务、信息边界和可恢复性条件；不宣称已证明现有融合算法的恢复保证。
代码核对记录见 [INFORMATION_BOUNDARY_AUDIT.md](INFORMATION_BOUNDARY_AUDIT.md)。

## 1. 一句话问题与暂定范围

已有服务发布一次性 LDP Top-m 统计摘要；新服务不访问用户，只利用这些摘要和可选的
公共目标业务上下文，估计其目标总体的 Top-k。研究重点是异构噪声、发布截断和分布迁移。

第一版采用以下工作约定。它们是问题适用范围，不是对现实数据已经核实的事实。

| 项目 | v1 约定 |
|---|---|
| 隐私单位 | 一名用户，一个类别值；固定参与集合上的值替换隐私 |
| 源用户关系 | 各源用户集合互不重叠；目标测试用户不在源用户集合中 |
| 物品 | 有限、公开、跨服务对齐的物品域，ID 语义一致 |
| 原服务 | 诚实执行公开机制，提供已扰动统计摘要 |
| 新服务 | 可以自适应处理已获取的发布，但不再查询或采样用户 |
| 目标 | 目标总体频率分布的 Top-k，不是源总体平均 Top-k |
| 上下文 | 可选的公开业务信息构造结果，不访问受保护用户记录 |
| 选源成本 | 获取全部发布后的估计策略；不声称因此减少下载通信 |
| 应用场景 | 用户已确认：暂时只定义通用问题，不绑定应用 |

重叠用户、多物品贡献、私有上下文、私有参与关系、恶意源是需要另设模型的扩展。
现有攻击实验可作稳健性压力测试，不能自动继承诚实发布的似然模型。

## 2. 统计对象与任务

公共域为 X={1,...,d}，实现使用等价的 0,...,d-1 编号。
源 s=1,...,S 的 n_s 名用户各贡献一个类别 X_su，基础采样模型为 X_su iid~p_s。
新服务对应的隐藏目标总体分布为 p_T，所有分布均在概率单纯形上。

目标集合为 T_k(p_T)=TopK(p_T)。实验使用频率降序、并列时按公开物品 ID 排序。
精确恢复讨论另要求边界间隔 Delta_k=p_T,(k)-p_T,(k+1)>0，避免边界并列歧义。
成功输出是大小 k 的集合；有序输出还用 NDCG 检查排名质量。

模拟器可知道 p_T；部署算法不可知道。真实数据中的隔离目标测试样本只能给出经验
Top-k，它与目标总体 Top-k 有采样差异，不能表述为无误差的总体真值。

## 3. 观察模型：算法实际输入

用户先经机制 Q_s 产生 epsilon_s-LDP 报告 Z_su。源端的聚合、选择和发布程序 H_s
仅使用已有报告与公开参数，形成 R_s=H_s(Z_s1,...,Z_sn_s; public metadata)。

拟定的完整公开接口是：

    R_s = (server_id, mechanism/version, n_s, epsilon_s, m_s,
           ordered L_s, {y_s,i, v_s,i : i in L_s}, release_rule)

y 是发布的频率统计量；v 是估计方差，不是已知真实误差。
release_rule 说明排序、负值处理、归一化、并列规则、方差计算与候选搜索方式。
n_s、epsilon_s 等只在其本来公开或由服务声明公开时可用；不得从隐藏配置偷取。
v1 要求频率和方差可见，只有榜单的发布属于另外的观察模型。

新服务器观察 O=(public domain, R_1,...,R_S, q or absent)。
部署输出必须能写成 A(O; h, xi)，其中 h 是预先固定或在独立开发数据上确定的超参数，
xi 是与用户记录无关的内部随机性。真实距离、生成器系数和目标标签不能混入 h。
公开的服务名字或 ID 也不能被用来解码模拟器隐藏的相似度顺序。

| 信息 | 部署可见性 | 来源/用途 |
|---|---|---|
| 物品 ID、语义映射、d、k | 可见 | 公共任务定义 |
| 发布榜单、频率、方差、公开机制参数 | 可见 | R_s |
| 榜单最小发布值、重合度、与 q 的相似度 | 可计算 | 对公开输入的后处理 |
| 未发布项目的估计频率 | 不可见 | 不能以完整估计数组形式传入 |
| 源用户记录、目标用户记录 | 不可见 | 生成/评估层隔离 |
| p_s、p_T、真实 Top-k | 仅评估可用 | 不得选择部署输出或调测试集参数 |
| 真实源目标距离、混合系数、潜在画像 | 仅模拟诊断可用 | 不是服务元数据 |
| 模拟随机种子 | 仅实验复现可用 | 不得重建隐藏分布作为算法输入 |
| 新增目标报告 | 禁止 | 超出零新增查询设定 |

信息边界的可检验标准：固定 O 和 h、xi，替换所有隐藏评估对象，部署预测不变。
随机算法对应输出分布相同。固定源发布而改变 q 的输出可以变化，因为 q 是允许输入。

## 4. 公共上下文的含义与来源约束

有上下文时 q=g(Z_T)，q>=0 且 sum(q)=1。Z_T 是公共服务定位、目录或其他允许资料。
g 不访问本研究受保护用户的记录；其规则在最终目标测试前冻结。
q 可以与 p_T 相关，但相关性不能来自偷偷使用目标测试标签。若使用预训练模型或
外部统计，应进一步说明训练数据/统计来源；“已公开”本身不能证明不涉及本研究用户。

无上下文是 absent，不是均匀向量，更不是 context_quality=0。稀疏 q 中零值若表示
未提供属性，则不能解释为真实用户概率为零；未来接口应带明确的缺失掩码。

现有合成实验满足：潜在业务画像 B 生成后，p_T 与 q 在给定 B 时独立采样。
这是条件独立，不是边缘独立。代码以浓度 24 生成 p_T，以 0.5+80*quality 生成 q。
quality 不是 TV 距离或恢复概率；端点 0/1 不代表无信息/完美信息。

用户已确认目前没有具体公共上下文资料或构造规则。因此本版不宣称现实中已获得 q，
结论限于“给定允许的公共上下文时”的条件性结果；合成实验只能验证这种条件设定。
每次真实数据研究须补全以下来源卡：

| 字段 | 必须填写的内容 | 当前状态 |
|---|---|---|
| 目标服务与目标总体 | 服务定位、纳入用户标准、时间范围 | 待确认 |
| Z_T | URL/文件、字段、版本和获取日期 | 待确认 |
| g | 公式/脚本、参数、冻结时间 | 合成规则已有；现实映射待确认 |
| 用户信息依赖 | 是否包含源/目标用户，是否需已有 DP 预算 | 待核实 |
| 开发与测试 | 参数选择用了哪些群体，哪些群体从未参与选择 | 待划分 |

## 5. 隐私命题与适用边界

对固定参与集合内的任意用户值 x,x' 和报告事件 E，若

    Pr[Q_s(x) in E] <= exp(epsilon_s) Pr[Q_s(x') in E]，

且 R_s、A 仅是既有报告与上述公共信息的后处理，则新服务器的全部后处理输出
不会增加相对于既有发布的隐私损失。证明直接应用 LDP 及差分隐私的后处理闭包。
这是一条条件命题，不是对每个端到端真实数据工作流完成了隐私认证。

源用户互不重叠且各贡献一次时，每名用户继承其所在服务的 epsilon_s 保证。
同一用户在多个服务重复报告时，基本组合界通常是相关 epsilon 的和；复用不增加
该已有损失，不会把组合损失“降回”单次 epsilon。若 q 另由这些用户的私有查询生成，
其已有查询预算也须组合。固定 n_s 的值替换保证不保护用户是否参与或群体成员身份。

发布 v 必须来自扰动统计及公开参数，不能从真实频数计算后当作免费附件发布。
PEM 需确保分组独立于用户值，每名用户只参加一个阶段，后续选择仅基于既有报告。
若对同一真实数据反复运行多种协议/种子并向同一观察者公布全部结果，需要计算整段
发布历史的隐私成本。模拟重复实验是在评估机制性能，不能把重复发布都算作“一次”。

## 6. 一般不可识别性与条件可恢复性

命题 1（无关联约束时不可保证精确恢复）：固定源分布、机制和公共 q（或无 q），
允许两个目标 p_T^a、p_T^b 拥有不同 Top-k，而不改变源发布的分布。这两个世界的
可见输入分布相同，所以任何算法的输出分布相同；两个正确集合互斥，成功概率之和
不超过 1。因此至少一个世界的精确恢复成功概率不超过 1/2。
这说明不存在对所有任意目标均可靠的估计器；不是说无上下文平均在任何实例都无效。
固定但与目标无关系约束的 q 同样不能排除这两个世界。

基础反例：d=2,k=1；两世界源分布相同，q=(0.5,0.5)，目标分别为 (0.9,0.1) 和
(0.1,0.9)。发布的分布完全相同，正确答案相反。一般 k 可固定 k-1 个高频项并交换边界项。

为研究条件性效果，v1 引入问题难度参数：

    TV(p_T,q) <= eta          （有 q 时）
    TV(p_s,p_T) <= rho_s      （指定源关系时）
    TV(p,r) = (1/2) * sum_i |p(i)-r(i)|。

eta、rho_s 暂作为分析参数，不作为当前部署算法已知输入。约束必须非平凡才有用；
把它们全设为 1 几乎不限制分布。未来若算法要用这些界，必须说明公开、可校准的来源。
当前混合生成器 p_s=alpha_s*p_T+(1-alpha_s)*r_s 是一个特定实验族，不是现实普遍定律；
alpha_s 和生成器的真实 rho_s 不可传给算法。

即便 n_s 趋于无穷，固定迁移偏差和不充分公共信息仍可能留下多个相容目标，不能
仅凭上述距离约束宣称一致恢复。后续理论应研究哪些条件下相容目标具有相同 Top-k。

命题 2（排序的充分条件）：若 Delta_k>0，候选 C 包含真实 T_k，且对所有 i in C 有
|p_hat(i)-p_T(i)| < Delta_k/2，则在 C 内取最大的 k 项恢复 T_k。
理由：任意真实 Top-k 项与其外项目的真实差至少 Delta_k，两个估计误差不能逆转顺序。
这没有证明现有算法满足误差前提；它给出未来误差分析需要达到的具体目标。

## 7. 候选和发布选择事件

源候选模式 C_source=union_s L_s。增强模式 C_aug=C_source union TopR_positive(q)，
其中只加入 q 的正质量项。算法需声明模式，并满足输出属于其候选集合。
候选型方法的 Recall <= |T_k intersect C|/k；不在 C 的真实目标项不可恢复。
context_only 的候选来自公共域/上下文，应独立说明，不能套用源候选上界。

自适应选源集合 J 是 R、q 的函数。现有非增强自适应方法一般在 union_{s in J}L_s
内评分；增强 censor-aware 使用传入的全源加公共候选集合。它们的可达集合不同。
现有指标常记录全源并集上界，是合法但偏宽的上界，不能解释成实际选源后的覆盖率。

GRR/OUE/OLH 当前发布过程：先计算全域未截断估计，按其值取 Top-m，再将已选频率
下截断到 0；不对发布列表重新归一化为和 1。v 从未截断估计的 plug-in 公式计算。
若最低已发布值为正，可对应原始选择阈值；若为 0，原始负阈值无法从发布值精确重建，
最多得到更弱的未发布值不大于 0 的条件。并列选择还需公开 ID 规则。

因此“未发布意味着低于阈值”不等于已经得到精确高斯删失似然。随机阈值、联合选择、
非负处理、方差估计和源目标偏差仍需分析。PEM 的未发布还包含前缀剪枝事件，
不能直接宣称所有未发布项都经过同一个全域频率估计并低于最终阈值。

## 8. 本步骤完成标准及未决事项

本工作稿已确定可见输入、禁用信息、目标、隐私单位、候选规则、不可识别反例及
条件恢复目标。代码差距逐项记录在审计文档；真实部署来源未落实的项目保持未决。

| 未决问题 | 临时处理 | 何时必须解决 |
|---|---|---|
| 具体服务与 q 的现实来源 | 先使用通用定义，公开上下文的真实来源尚未落实 | 真实数据主实验前 |
| eta/rho 的可校准约束 | 当前仅分析/评估参数，不喂给算法 | 提出依赖它们的方法/定理前 |
| 仅榜单或缺方差的服务 | v1 不支持，不能靠当前开关声称支持 | 扩大观察模型前 |
| 多事件和群体筛选隐私 | v1 排除；后续数据集需单独定义贡献单位与参与条件 | 声称真实用户级 LDP 前 |
| 理论主要协议范围 | 先分析全域频率协议，PEM 单列搜索遗漏近似 | 删失理论定稿前 |
